Before you paste

Your page needs the WSU kit script loaded for these to render. If you are working in a WSU Web Design System site, it is already there.

If the icon is decorative and the text beside it already says what the control does, keep the aria-hidden="true" that comes with the copied tag so screen readers skip it.

If the icon is the only thing identifying a button or link, give that control an accessible name with aria-label. An unlabeled icon-only control fails WCAG 4.1.2.

Icons that carry meaning need 3:1 contrast against their background. WSU crimson and dark gray both clear that on white. Light gray does not, at 1.65:1.
